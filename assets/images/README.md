# Images

Public images live in `assets/images/uploads/` and are selected through Decap CMS. New JPEG, PNG, and WebP uploads are converted to WebP in the browser before they are saved to GitHub. The image fields use 900 px wide film posters, 256 px wide people portraits, 400 px wide company logos, and 1200 px wide hero photos. The Media Gallery defaults to 1600 px. SVG and GIF files pass through unchanged; use SVG for simple logos where a vector original exists. The About carousels use the images marked `small` in `data/hero.json`.
